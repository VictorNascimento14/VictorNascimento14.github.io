## O que muda

- `relogio.js`: um só `requestAnimationFrame` para o site inteiro; cada parte registra uma tarefa e o laço dorme quando nada anima.
- `pixel.js`: pixel inteiro no pixel de dispositivo, canvas sem suavização, sorteio com semente (mulberry32) e as curvas do site.
- `memoria.js`: o que o site lembra, em `localStorage` com prefixo e tudo protegido (janela privada não quebra nada).
- `sinais.js`: avisos entre as partes sem import cruzado, com histórico para quem carrega depois.
- `movimento.js`: movimento reduzido lido ao vivo.
- `rolagem.js`: rolagem por telas com mola criticamente amortecida (7/s), um gesto = uma parada, teclas e âncoras, e a trava da primeira tela com as suas válvulas (90 s, erro, foco, âncora, volta).
- `docs/arquitetura.md` (contratos e decisões) e `docs/imagens.md` (as imagens que o Victor gera).

## Por quê

São as peças que todas as seções usam: o mesmo relógio, as mesmas regras de pixel e o mesmo canal de avisos.

## Como testar

`npm run lint`. O efeito aparece com as seções, a partir do herói.

## Revisão

Rodada r1: `acordar()` chamado dentro de um quadro abria uma segunda cadeia de `requestAnimationFrame` que nunca se juntava à primeira (chegou a 28 execuções por quadro): agora é uma só. Erro numa tarefa vai para `reportError`, a válvula que solta a trava. O `touchmove` cancelável só existe com a página presa, e as teclas de página não deslizam o fundo com janela ou jogo modal aberto. O Chromium não dispara `change` do movimento reduzido quando `matches` é lido a cada quadro: a troca é detectada comparando com o último valor.
